# 📜 Reduto dos Pergaminhos (Grimório Digital)

Um leitor de PDFs imersivo com visual e temática medieval, desenvolvido com **HTML5**, **CSS3**, **JavaScript**, **PDF.js** e a biblioteca **St.PageFlip** para simular a virada de páginas de um livro real.

## 🧙‍♂️ Funcionalidades
* **Carregamento de PDF Local:** Escolha qualquer arquivo PDF do seu dispositivo para ser desdobrado no grimório.
* **Efeito de Virada de Página Real:** Páginas renderizadas dinâmicamente com animação de folheamento.
* **Tela de Carregamento Temática:** Avisos imersivos enquanto as crônicas são processadas em segundo plano.
* **Design Responsivo e Fixo:** Layout travado centralmente com setas laterais de navegação estilizadas.

## 🚀 Tecnologias Utilizadas
* HTML5 / CSS3 (com fontes customizadas e layout flexbox)
* JavaScript Moderno (ES6+)
* [PDF.js](https://mozilla.github.io/pdf.js/) (para processamento e renderização de PDFs)
* [PageFlip](https://github.com/nodlik/StPageFlip) (para o efeito de livro animado)
